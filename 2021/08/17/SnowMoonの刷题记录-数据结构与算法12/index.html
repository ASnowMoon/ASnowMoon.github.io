10-排序4 统计工龄 (20 分)

给定公司N名员工的工龄，要求按工龄增序输出每个工龄段有多少员工。

输入格式:

输入首先给出正整数N（≤105），即员工总人数；随后给出N个整数，即每个员工的工龄，范围在[0, 50]。

输出格式:

按工龄的递增顺序输出每个工龄的员工个数，格式为：“工龄:人数”。每项占一行。如果人数为0则不输出该项。

输入样例:

输出样例:

这题取了个巧，都没排序，直接按照工龄从低到高且不为空顺序输出了

#include<stdio.h>
#include<stdlib.h>

int main()
{
    int i, x, n;
    scanf("%d", &n);
    int s[51] = {0};
    for(i = 0; i < n; i ++) {
        scanf("%d", &x);
        s[x] ++;
    }
    for(i = 0; i <= 50; i ++) {
        if(s[i]) {
            printf("%d:%d\n", i, s[i]);
        }
    }

    return 0;
}
